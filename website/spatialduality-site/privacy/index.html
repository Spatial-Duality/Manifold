Privacy

Manifold is designed as a local control layer. Governed file, email, prompt-adjacent, and scanner data stay on the Mac unless the user exports something explicitly.

Diagnostic reports are export-only in v1. They are previewable JSON and do not include file paths, prompts, email contents, governed data, raw stack traces, cookies, or IP addresses.

Automatic update checks are off until enabled. Manual update checks and app downloads contact GitHub Releases and the Sparkle appcast.

Website analytics are opt-in. The Cloudflare Web Analytics beacon is not loaded until a visitor chooses Allow.

The optional Fast Local Scanner model is downloaded from Hugging Face only after the user starts the download in the app.

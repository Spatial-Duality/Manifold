# Code of conduct

Manifold is a security-sensitive macOS project. The project works best when
discussion is direct, technical, and respectful.

## Expected behavior

- Be precise and constructive in issues, reviews, and discussions.
- Assume good faith while still being rigorous about security and correctness.
- Disagree with ideas and implementation choices, not people.
- Keep reports focused on reproducible behavior, risk, and verification.
- Respect private disclosure for security issues.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private information without explicit permission.
- Publicly disclosing unresolved vulnerabilities.
- Spam, trolling, or repeatedly derailing technical discussion.

## Enforcement

Maintainers may edit, hide, or delete comments; close issues or pull requests;
temporarily or permanently block participants; or take other reasonable action
to protect the project.

If you need to report conduct concerns, contact security@spatialduality.com.
For vulnerabilities, use the private process in [SECURITY.md](SECURITY.md).

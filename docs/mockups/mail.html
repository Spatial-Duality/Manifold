Getting started

What you'll see

after you connect your first mailbox

Once a mailbox is connected, this view fills in with:

1
Coverage matrix

One row per mailbox. Toggle each agent on or off. Set a sensitivity per mailbox — subjects only, trusted senders, or full content.

2
Thread picker (Active Backup style)

Sender rail on the left, dense thread table, checkboxes. Pick individual threads — not your whole inbox. Running count at the bottom keeps you oriented.

3
Session overlays

Spin up a time-boxed session with extra threads for a specific task. Expires automatically. Default never drifts.

4
Denial counts

If an agent tries to read a thread you haven't shared, Manifold blocks it and records the attempt. You decide whether to grant.

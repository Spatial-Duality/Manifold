Foundation

Ten principles. One hierarchy.

Every surface decision is traceable to one of these. Load-bearing order: honesty first, trust by evidence second, posture third. Everything else inherits.

1

Honesty outranks confidence.

Reliability over polish. The UI must not be more confident than the state. No green dots over a broken runtime. No "Connected" where "Not recording" is true.

Norman · CLAUDE.md · Ink & Switch
2

Trust is earned by visible evidence.

Security products fail when they only assert. Manifold's ledger is the asset — dense, position-encoded, one-click drill to the bytes that changed.

Tufte (VDQI · EI · BE) · Few (IDD · NYS) · Johnny · S&U
3

Daemon posture. Not sovereign.

Manifold wins when users forget it's running. Menu bar is the primary surface. The Ledger window is secondary, invoked rarely. Never sovereign chrome.

Cooper (About Face) · Apple HIG · Raskin
4

Modelessness. Never hijack attention.

No modal approvals. A queue that accumulates quietly. The user decides on their schedule. Every mode taxes the user's locus of attention.

Raskin (Humane Interface) · Whitten & Tygar
5

Defaults carry moral weight.

Nothing shared until you share it. "Not this time" is the focused approval default. .env excluded by default. The product's ethics live in its defaults.

Thaler & Sunstein (Nudge) · Cranor/Garfinkel
6

Language is the product.

No engineering vocabulary in the UI. "You've shared 4 folders with Claude" — user as subject for choices, agent as subject for actions. Two voices, used on purpose.

Yifrah · Podmajersky · Nicely Said · Evans
7

Scope is a spatial primitive.

Not a checkbox list. Sources × agents is a coverage matrix (Bertin's position encoding). Access is a map of what each agent sees.

Alexander (APL · NSF) · Bertin · MacEachren
8

Direct manipulation. Every exposure is a handle.

Ledger rows are not display-only. Right-click an event to revoke, revert, or exclude. The evidence is actionable from where you find it.

Bret Victor (Magic Ink) · Tufte · Ink & Switch
9

Density with rhythm.

4pt baseline, tabular numerics, fixed-width timestamps. Dense views reward close reading. Polish without typographic discipline is noise.

Bringhurst · Hochuli · Lupton · Müller-Brockmann
10

Color-as-identity ≠ color-as-state.

Claude blue and Codex violet are fixed. Session green and attention orange are fixed. Never tied to the user's system accent. Every status carries a second channel — icon or text.

Albers (IoC) · Bertin · Ware (IV)

Evolution

Ten stages of being wrong.

The design arrived at its current shape by being wrong, explicitly, several times. Every correction is preserved in the docs. Here's the arc.

01Critique

Manifold is pretending to be sovereign.

Honest audit of the existing code against the reading list. Grade: B-. Root finding: the app was built with sovereign chrome (three-tab picker, big main window) but its job is a daemon's. Every downstream decision cascaded from this.

02Posture

Daemon with two visible surfaces.

Resolved the posture question: menu bar panel is primary; Ledger window is secondary. Delete the Overview tab; delete the three-tab picker. Ten principles established, ordered by load-bearing priority.

03Surfaces

Fifteen surfaces, each traced to sources.

A–O: first-run, add/remove files, add/remove emails, workspace/scope, exposure ledger, approval queue, version history, connection state, menu bar, sidebar, inspector, settings, empty/error/denial, microcopy, type & grid. Every decision cited to one of the 45 books.

04First visual

HTML mid-fi mockups — menu bar, Ledger, Scope.

First visual pass of the highest-leverage surfaces. Unified "Access" matrix with folders + mailboxes in one table. Aesthetically fine; structurally wrong on two counts.

05Addendum

Per-file selection. Global rules. User-as-subject copy.

Three gaps caught: folders treated as atomic (file tree added to inspector), global rules collapsed into per-mailbox (pulled up to a new Rules surface), status sentences put the user in the grammatical driver's seat. Nav renamed: Ledger → Activity, Scope → Access, Queue → Requests.

06Sessions

Default + Session + Reload. The missing primitive.

A named, time-bounded overlay on top of persistent default access. Every session is recallable with a drift diff. Collapses work block, transient share, and one-time approval into one concept. Survives every book on the list.

07Mail split

Files and email deserve separate surfaces.

The unified matrix from Stage 4 didn't survive the Stage 6 session model. Frequent selection needs first-class real estate. Nav: Activity · Access · Mail · Requests · Rules.

08Mail UI

Active Backup style, not Apple Mail.

Operator chrome. Sender rail, dense thread table, running count at the bottom. No reading pane — a reading pane signals read here and Manifold is not a mail client. Mail-native row content (subject, sender disc, thread collapse) is borrowed; mail-client chrome is rejected.

09Rebuild

First pass at full HTML mockups failed the quality bar.

Emoji iconography, muted palette, no depth. Honest: the output looked like a Notion page, not a product. Pivoted briefly to a Swift spike; user rejected that too. Course correct: HTML at real visual fidelity.

10Language locked

This page. Real glass, saturated palette, inline SVG, layered depth.

Every surface composed from shared tokens. Every icon inline. Every chip a gradient. Every shadow layered. Every number tabular. Next: ship it in Swift, one surface at a time, starting with the menu bar panel.

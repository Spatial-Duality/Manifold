Getting started

What you'll see

after you share your first folder

Once a folder is shared, this view fills in with:

1
Coverage matrix

One row per shared folder. Toggle each agent on or off. See how many files each can see, and how many are excluded.

2
File-tree inspector

Drill into any folder. Exclude specific files or subfolders with tri-state checkboxes. Smart defaults pre-exclude sensitive patterns.

3
Session overlays

Spin up a time-boxed session that adds or removes folders just for a task. Expires automatically.

4
Denial counts

If an agent tries to reach a folder you haven't shared, Manifold blocks it and records the attempt — you decide whether to grant.

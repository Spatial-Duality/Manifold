# Design Review

Review Manifold like a serious desktop product, with Pixelmator Pro as the benchmark.

## Scorecard

Always evaluate these dimensions:

1. Reliability and trust
2. Navigation coherence
3. macOS-native fit
4. Information density and clarity
5. Performance and responsiveness
6. Visual polish

## Output

- Grade the app overall.
- Call out the highest-impact issues first.
- Anchor feedback to specific files and UX flows.
- Separate "concept is strong" from "execution is finished".

## Manifold-specific focus

- The core question is whether the user can trust what the app says AI can see or do.
- A polished surface does not outweigh broken runtime registration, guessed status, or sluggish file/search flows.
- Treat folder access, tracked work, and activity review as first-class pro workflows.
